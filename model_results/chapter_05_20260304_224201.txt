**Конфигурация сервисов:**

- **SSH:** Версия OpenSSH 9.6p1, настроен для удаленного доступа пользователей.
- **SMTP:** Версия Postfix smtpd, настроен для отправки и приема электронной почты.
- **DNS:** Версия ISC BIND 9.18.39, настроен для разрешения доменных имен.
- **HTTP:** Версия Apache httpd 2.4.58, вероятно, настроен для обслуживания веб-содержимого.
- **IMAP:** Версия Dovecot imapd, настроен для обработки электронной почты.
- **SSL/IMAP:** Версия Dovecot imapd, настроен для безопасного доступа к электронной почте.
